# 呆饼问题（二）：听牌信息的排列编码问题

> **研究版本：** 2026-10-19 · 定义与等价性证明稿  
> **研究目标：** 明确题目的输入、允许操作、输出、量词和最优性要求；分别定义「自适应逐张查看」与「预先固定位置查看」。  
> **状态说明：** 本文给出问题的严格定义以及**两种查看模型等价**的证明；**不声称已证明最优值为 4**。

## 1. 面向非专业读者的题面

使用一副标准日式麻将牌：共 **34 种牌，每种 4 张，合计 136 张**。不考虑花牌、副露、吃、碰、杠、赤宝牌、役种、番数及其他对局历史信息。每张牌仅用其牌种区分，同种牌的四个实体彼此不可区分。

电脑给「呆」一副**恰好 13 张、已经听牌**的手牌。所谓听牌，是指至少存在一种尚有实体牌可用的牌种，加上一张后，能够构成合法的 14 张和牌结构。听牌种类可以有多个；例如可能同时听三万和六万，也可能是国士无双十三面听、纯正九莲宝灯九面听。

呆能看到全部 13 张牌，知道完整的听牌结果；「饼」看不到任何牌面。双方在游戏开始**之前**可以共同约定一套任意复杂、但对所有输入统一适用的规则。然后：

1. 呆只可以将**原有的这 13 张牌**重新排列到桌面上 13 个固定位置，位置标号为 1 至 13，所有牌均背面朝上。不得增减、替换、标记牌，不得用牌的朝向、间距、摆放时间、声音、表情等其他方式传递信息。
2. 呆完成摆放后离场；饼只看得到 13 张无区别的牌背，以及固定位置标号。
3. 饼按照事先约定的规则翻看至多 $`k`$ 张牌，并报告**所有有效听牌牌种构成的集合**。不要求还原另外未翻开的牌，也不要求还原整副手牌。
4. 无论电脑给出的是哪一副合法的 13 张听牌手牌，报告都必须**完全正确**，不能漏报、多报，也不能以高概率正确代替保证正确。

**问题：最少翻开多少张 $`k`$，才能设计出满足上述要求的编码、解码协议？**

这里所谓「编码」，是呆利用**牌种的排列次序**传递信息；「解码」，是饼根据有限次看到的**牌种及其所在位置**，恢复出完整听牌集合。牌背本身没有任何可区分的标记。

本文分别讨论两种查看方式：

- **模型 A——自适应顺序查看：** 饼可以先翻第一张，再根据已看到的信息决定第二张翻哪里，依此类推。
- **模型 B——预先固定位置查看：** 饼在未见任何牌面之前，就必须按共同约定确定要翻开的 $`k`$ 个位置；然后从这些位置获得牌面信息，不因翻牌结果更换位置。

## 2. 基础数学对象

### 2.1 牌种与物理库存

定义牌种集合

```math
T=\{1m,\ldots,9m,\;1p,\ldots,9p,\;1s,\ldots,9s,\;E,S,W,N,P,F,C\},
\qquad |T|=34.
```

其中 $`m,p,s`$ 分别为万、筒、索；七个字牌符号分别对应东、南、西、北、白、发、中。

一副手牌是 $`T`$ 上的多重集合 $`H`$，其牌种 $`t`$ 的重数记为 $`c_H(t)`$。允许的 13 张手牌满足

```math
\sum_{t\in T}c_H(t)=13,\qquad 0\le c_H(t)\le4\quad(t\in T).
```

同一种牌的四个物理副本没有额外编号、痕迹或可读取的区别。

### 2.2 合法的 14 张和牌结构

记 $`\mathcal G`$ 为下列三类 **14 张多重集合**的并集，且每种牌的重数均不得超过 4：

1. **标准型：** 四个面子加一个雀头（对子）。每个面子为同一花色内连续的三张数牌（顺子），或三张同种牌（刻子）；雀头为两张同种牌。按多重集合分解，不区分面子的排列顺序。
2. **七对子：** 恰有七种互不相同的牌种，各出现两张；不得把同种四张算作两组对子。
3. **国士无双：** 由十三种幺九和字牌各一张，加上其中一种的第二张组成。十三种牌为每种数牌的 $`1`$ 和 $`9`$，以及七种字牌。

这里「和牌」只判定**牌面组合结构**，不是根据具体对局状态判定能否荣和、自摸或是否具有足够番数。九莲宝灯的牌型自然包含在标准型结构之内，无须额外作为第四类和牌结构。

### 2.3 听牌集合

对一副 13 张手牌 $`H`$，定义其**有效听牌集合**：

```math
W(H)=\left\{t\in T:\ c_H(t)<4\ \land\ H\uplus\{t\}\in\mathcal G\right\}.
```

$`H\uplus\{t\}`$ 表示再加入一张牌种 $`t`$ 的牌。约束 $`c_H(t)\lt 4`$ 排除了不存在的第五张同种牌。

定义**全部允许输入**：

```math
\mathcal H=\left\{H:\sum_{t\in T}c_H(t)=13,\ \forall t\ 0\le c_H(t)\le4,\ W(H)\ne\varnothing\right\}.
```

对全部 $`H\in\mathcal H`$ 均必须保证成功；「随机生成」仅说明实例如何选取，不引入概率分布，也不改变这个全称量词。

**输出对象是 $`W(H)`$，而不是 $`H`$ 本身。** 两副完全不同的手牌即使拥有相同的听牌集合，也允许产生相同的编码消息。

#### 听牌范围示例

- 若 $`W(H)=\{3m,6m\}`$，则必须同时报告三万、六万。
- 国士无双十三面听对应含 13 种幺九和字牌的集合。
- 13 张基本九莲形 $`1112345678999`$（同一种花色）对应 $`1`$ 至 $`9`$ 的九面听。
- 若 $`c_H(6m)=4`$，则 $`6m\notin W(H)`$，即使在某种不考虑库存的形式表达中 $`6m`$ 看似能够补成某种形状，也不得虚构第五张六万。

**避免误读：**「纯正九莲宝灯九面听」的上述标准 13 张基底本身不会含四张六万；「手中四张六万须排除六万」是一般库存约束示例，不能把它当成同一副纯正九莲手牌的实例。

## 3. 共同的编码阶段

记 $`\operatorname{Perm}(H)`$ 为多重集合 $`H`$ 的所有不同的长度为 13 的有序排列。呆和饼可事先共同约定一个**确定性的编码函数**

```math
E:\mathcal H\longrightarrow T^{13},\qquad E(H)\in\operatorname{Perm}(H)\quad(\forall H\in\mathcal H).
```

对于输入 $`H`$，呆把 $`E(H)_i`$ 放在位置 $`i`$，全部背面朝上。该函数不得偷偷引入牌外通信渠道，也不得改变重数。呆随后离场。

允许呆事先计算 $`H`$ 和 $`W(H)`$，并依此选择编码；饼事先知道函数 $`E`$ 及全部解码规则，但在翻牌前不知道本次输入 $`H`$。

## 4. 模型 A：自适应逐张查看

给定观察次数上限 $`k`$，饼事先确定一个确定性决策规则：

- 第一次查询位置 $`q_1\in\{1,\ldots,13\}`$；
- 第 $`j`$ 次查询位置为

  $`\displaystyle q_j(v_1,\ldots,v_{j-1})\in\{1,\ldots,13\}\setminus\{q_1,\ldots,q_{j-1}\},`$

  其中 $`v_i`$ 是之前第 $`i`$ 次翻出的牌种，且这里的历史位置 $`q_i`$ 由已知规则唯一确定；
- 第 $`j`$ 次观察得到 $`v_j=E(H)_{q_j(v_1,\ldots,v_{j-1})}`$；
- 最多进行 $`k`$ 次查询，最后用事先固定的解码规则输出一个 $`T`$ 的子集。

可以允许提前停止。为方便比较，只需把提前停止的协议用「再读若干未读位置但忽略其结果」的方式扩充到**恰好** $`k`$ 次；这不会改变答案。因此以下均以恰好读取 $`k`$ 次表述。

因为查询位置是此前观察的确定性函数，所以完整的查询位置历史可以由观察到的有序牌种序列 $`(v_1,\ldots,v_k)`$ 重建。可将最终解码规则写为 $`D_A:T^k\to\mathcal P(T)`$。

定义模型 A 的最优值：

```math
 k_A=\min\left\{k\in\{0,\ldots,13\}:\exists\ E,\ (q_j)_{j\le k},\ D_A\ \text{使}\ \forall H\in\mathcal H,\ D_A(v_1,\ldots,v_k)=W(H)\right\}.
```

其量词含义是：**存在一套统一协议，使任意合法手牌都能被正确解码**；不是对每副牌临时重新商量另一套规则。

## 5. 模型 B：预先固定位置查看

在看到本次手牌的任何牌面之前，双方共同约定 $`k`$ 个不同的查询位置

```math
I=(i_1,\ldots,i_k),\qquad i_j\in\{1,\ldots,13\},\quad i_a\ne i_b\ (a\ne b).
```

饼只能查看这些位置，观察的有序结果为

```math
 v=(E(H)_{i_1},\ldots,E(H)_{i_k}).
```

注意：即使一次翻开全部 $`k`$ 张，**牌面和各自的位置仍然可见**，因此观察结果仍是位置标记的有序 $`k`$ 元组，而非无序多重集合。

事先约定解码函数 $`D_B:T^k\to\mathcal P(T)`$，要求

```math
\forall H\in\mathcal H,\qquad
D_B(E(H)_{i_1},\ldots,E(H)_{i_k})=W(H).
```

定义模型 B 的最优值：

```math
 k_B=\min\left\{k\in\{0,\ldots,13\}:\exists\ I,E,D_B\ \text{使上述条件对所有}\ H\in\mathcal H\ \text{成立}\right\}.
```

由于 13 个位置事先可以统一重命名，研究时不失一般性，可取

```math
 I=(1,2,\ldots,k).
```

这个约定表示固定查看前 $`k`$ 张，而不是假设呆原本会以某种自然的麻将顺序排列手牌：**呆依然可以任意排列他实际拥有的全部 13 张牌。**

## 6. 定理：在上述约束下，自适应与固定位置的最优值相等

> **定理（两种观察协议等价）**  
> 若（i）呆可以任意排列全部 13 张牌；（ii）双方预先共享确定性协议；（iii）牌背相同，位置之外没有侧信道；（iv）饼的查询位置仅依赖此前翻开的牌面及公开已知规则，那么对每个 $`k`$：模型 A 可行当且仅当模型 B 可行。因此
>
> ```math
> \boxed{k_A=k_B.}
> ```
>
> 此结论**不需要预先知道最优值是 3、4 或其他整数**。

**证明。**

1. **B $`\Rightarrow`$ A：** 在自适应模型中，饼完全可以选择不根据已看到的信息改变查询位置，直接按模型 B 的固定位置查阅。于是 $`k_A\le k_B`$。
2. **A $`\Rightarrow`$ B：** 任取一个可以保证成功的模型 A 协议，其编码函数为 $`E_A`$，查询规则为 $`q_1,\ldots,q_k`$，解码规则为 $`D_A`$。对每一副手牌 $`H`$，按该协议实际运行后，会得到一个确定的**有序观察序列**\
   $`\displaystyle v(H)=(v_1(H),\ldots,v_k(H)).`$\
   由于模型 A 只查询互不重复的位置，$`v(H)`$ 中每种牌的出现次数都不超过 $`H`$ 中的存量。因此，呆可以改用新的编码 $`E_B`$：把 $`v_1(H),\ldots,v_k(H)`$ 依次摆在**固定的前 $`k`$ 个位置**，再把剩余的 $`13-k`$ 张牌任意排列在后面。这样 $`E_B(H)\in\operatorname{Perm}(H)`$，完全符合编码约束。饼固定读取前 $`k`$ 个位置，得到的恰好是原模型 A 的观察序列 $`v(H)`$，于是直接应用 $`D_A`$ 就能输出 $`W(H)`$。因此 $`k_B\le k_A`$。
3. 两个方向合并，得 $`k_A=k_B`$。$`\square`$

**直观解释：** 自适应协议原本可能依次查过位置 $`7,2,11,5`$，得到四个有序牌种。由于呆知道全部手牌、双方协议和最终查询路径，他可以直接把这四张牌按照**同样的观察顺序**放到位置 $`1,2,3,4`$。位置路径本身没有额外需要传递的独立信息，因为它完全由已看到的牌种和预定规则决定。

**研究意义：** 两种形式可以分别保留为题面变种，但在现有假设下，它们不会给出两个不同的最小翻牌数。可以优先求解结构更简单的模型 B；其最优性结论将同时适用于模型 A。

## 7. 消除具体查询过程后的统一组合数学形式

对每副手牌 $`H`$，定义其可以排列出的全部长度为 $`k`$ 的**有序消息**：

```math
A_k(H)=\left\{(t_1,\ldots,t_k)\in T^k:\ \forall t\in T,\ \#\{j:t_j=t\}\le c_H(t)\right\}.
```

即不能在一条消息中使用超出手牌库存的任何牌。

于是上述两个模型共同的最优值，也可以**完全不涉及桌面位置**地定义为

```math
\boxed{\displaystyle
k^*=\min\left\{k\in\{0,\ldots,13\}:\exists f:\mathcal H\to T^k,\ \forall H\ f(H)\in A_k(H),\ \forall H,H'\ \bigl(f(H)=f(H')\Rightarrow W(H)=W(H')\bigr)\right\}.
}
```

这里的 $`f(H)`$ 是呆用前 $`k`$ 张牌编码的消息。同一条有序消息可以被具有**相同听牌集合**的不同手牌复用；但不能被听牌集合不同的手牌同时使用。

等价地，记 $`\mathcal W=\{W(H):H\in\mathcal H\}`$ 为所有确实能够出现的听牌集合，则寻求互不相交的消息集合 $`(C_w)_{w\in\mathcal W}`$，满足

```math
\forall w\ne w',\ C_w\cap C_{w'}=\varnothing,
\quad\text{且}\quad
\forall H\in\mathcal H,\ A_k(H)\cap C_{W(H)}\ne\varnothing.
```

这个形式直接给出了一个有限的**零错误编码 / 约束满足问题**，适合做枚举、构造证明或 Lean 形式化。

基本边界为

```math
1\le k^*\le13.
```

上界成立，因为翻开全部 13 张牌后可以直接计算听牌集合；下界成立，因为存在至少两种不同的听牌集合，因此零张牌不够。

## 8. 对「最优答案是四张」的准确表述

目前可研究的候选命题是

```math
\boxed{k^*=4.}
```

要证明它，必须同时完成：

- **可行性（上界）：** 给出一套对所有 $`H\in\mathcal H`$ 都有效的四张编码与解码方案，或者给出足以完整验证这一事实的可复现程序/形式化证书，即 $`k^*\le4`$。
- **最优性（下界）：** 证明不存在对全部 $`H\in\mathcal H`$ 适用的三张（及以下）编码方案，即 $`k^*\gt 3`$。

「枚举了几百万或几千万种某一类手牌」只有在**覆盖了全部输入类别和重叠情况**、计算规则完全与第 2 节一致、并且能验证编码冲突条件与完整性时，才足以支撑相应证明。仅根据他人的结果描述，不能断言上述两个目标已全部证明。

## 9. 与本文两个主模型不同的额外变种（暂不研究）

以下改动**会改变问题定义**，原则上可能改变最优值；它们不是本文的主要两种模型。

1. **翻牌位置对呆保密或由对手任意指定：** 若呆摆好后必须保证**任何** $`k`$ 个位置被翻开时都能解码，这不是模型 B。模型 B 的固定位置是双方**事先共同约定**、呆可以利用的；「任意位置均必须成功」具有额外的全称量词，要求更强。
2. **同时翻开但打乱位置：** 如果饼只得到 $`k`$ 张牌的**无序多重集合**，并不知道每张牌原来属于哪个被选位置，则排列所承载的信息会减少；这不同于模型 B。
3. **限制呆的排列：** 比如只允许把手牌按麻将习惯排序，或者只允许交换少数位置，则第 6 节的等价性证明不再直接适用。
4. **要求重建全部手牌：** 将目标由 $`W(H)`$ 改为 $`H`$ 是另一个更强的通信任务；本文不研究。

## 10. 最终采用的正式问题陈述（精简版）

**定义：** 令 $`T`$ 为 34 种标准日式麻将牌的牌种集合，每种牌最多四张。令 $`\mathcal G`$ 是标准四面子一雀头、七个不同对子及国士无双构成的全部合法 14 张和牌多重集合。对任意 13 张手牌 $`H`$，以

```math
W(H)=\{t\in T:c_H(t)<4,\ H\uplus\{t\}\in\mathcal G\}
```

表示全部有效听牌牌种，令 $`\mathcal H`$ 为全部满足 $`W(H)\ne\varnothing`$ 的合法 13 张手牌。

**通信协议：** 发送者获知 $`H`$，只能重排其 13 张实体牌并全部背面朝上置于有标号的 13 个固定位置；接收者不知道 $`H`$，只知道事先共同约定的规则，至多查看 $`k`$ 个不同位置的牌面后，必须报告恰好为 $`W(H)`$ 的集合。禁止其他一切侧信道。要求同一协议对每一副 $`H\in\mathcal H`$ 均正确。

**待求：** 最小整数 $`k^*`$。分别允许（A）接收者根据先前翻牌结果自适应选择后续位置；（B）接收者在看到任何牌面之前固定全部查看位置。**在此模型下可证明 $`k_A=k_B=k^*`$**；所以只需求一个共同的最优值，并给出构造及不可能性证明。

---

**本文的边界：** 已固定数学对象、规则及两种协议的等价性；尚未求出或验证 $`k^*`$ 的具体数值。任何声称「最少四张」的结论，仍需单独提供严密的上界构造及下界证明。
